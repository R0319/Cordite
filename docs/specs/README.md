## このModの目標

- リアリティが強い銃Mod
- 戦闘体験がメイン（カスタムはある程度深いが、複雑になりすぎない）
- その銃Modに対応した敵の追加
- ダンジョンのように基地を生成させる
- gunpackシステムによりコミュニティが銃を追加できる

各項目の確度を示す。エージェントは「✅ 確定」以外を権威ある値として扱わないこと。

| タグ | 意味 |
|-----|------|
| ✅ 確定 | 決定済み。実装はこれに従う |
| 🟡 仮 | 暫定。変更の可能性あり |
| 🔵 検討中 | 方向性は議論中 |
| ⬜ 未定 | 未決定。プレースホルダ |

## 用語集

| 用語 | 意味 |
|-----|------|
| gunpack | コミュニティが銃・アタッチメント・レティクル等を追加するためのJSONベースの配布単位（tacz参考） |
| レール | 銃に付いたアタッチメント取り付け軸。`top`/`bottom` 等。スロット数（`length`）を持つ |
| アタッチメント | サイト・マガジン・マズルデバイス・ストック・ウェポンライト等の装着物 |
| マズルデバイス | 銃口に付ける装置（サプレッサー／フラッシュハイダー／マズルブレーキ／銃剣） |
| レティクル | サイトの照準マーク画像 |
| ADS | Aim Down Sights。照準を覗く動作 |
| PiPスコープ | Picture-in-Picture。別カメラでレンズ内を描画する高品質ズーム方式 |
| 疑似ズーム | レンズ部分のFOVのみ変更する軽量ズーム方式（デフォルト） |
| FOV | 視野角。サイト位置や疑似ズームで変化する |
| オープン/クローズドボルト | 発射前のボルト位置による分類。装填挙動・薬室内弾薬の扱いが変わる |
| 薬室（ボルト内弾薬） | マガジンとは別に薬室へ1発装填されている状態。リロードモーションが変化する |
| ジャム | 耐久劣化により発生する動作不良 |
| 機関部 | 銃の耐久値を回復させる交換パーツ |
