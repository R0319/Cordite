# 02. 銃仕様 🟡 仮

> **範囲**: アタッチメント種別、マズルデバイス、サイト/照準（PiP・疑似ズーム）、耐久劣化、リーン機能。銃のラインナップ自体は [03-items.md](03-items.md) を参照。
> 用語・凡例は [README.md](README.md) を参照。

## 🟡 仮値（要調整）

> 以下の数値はすべて**仮確定**。バランス調整で後から変更する前提のプレースホルダ。

### ダメージ計算式（仮）

```
命中ダメージ = 基礎ダメージ × 距離係数 × 部位倍率 × (1 − 防具軽減率)
```

- プレイヤー体力はバニラ準拠 20（ハート10）
- 部位倍率（仮）: 頭 2.0 / 胴 1.0 / 手足 0.75
  - 部位の境界判定（🟡仮・実装値）: 命中点の高さがエンティティ身長の **85%以上 = 頭 / 35%以下 = 手足 / その間 = 胴**（[../design/firing.md](../design/firing.md) と連動）
- 距離係数（仮）: 「減衰開始」距離まで 1.0。以降「有効射程」まで 0.5 へ線形低下。射程超過後は 0.5 固定
- 防具軽減率は [03-items.md](03-items.md#防具仕様) を参照

### 発射モード・ボルト方式（仮）

実装済みの銃のみ確定扱い。未実装の銃は追加時に決める。

| 銃 | 発射モード | ボルト方式 | 撃ち切りホールドオープン |
|----|-----------|----------|------------------|
| グロック | 単発のみ | クローズド | あり（スライドストップ） |
| AK系 | 単発 / フルオート | クローズド | なし（ボルトキャッチ無し） |
| M4系 | 単発 / フルオート / バースト | クローズド | あり（ボルトキャッチ） |
| その他 | ⬜未定 | ⬜未定（LMG / 一部SMG はオープンボルト候補） | ⬜未定 |

ホールドオープンする銃は撃ち切り後スライド／ボルトが後退保持され、**空撃ち音が鳴らない**（見た目・音の扱いは [06-animations.md#撃ち切り時のホールドオープン-仮](06-animations.md#撃ち切り時のホールドオープン-仮)）。

### 反動（仮）

**視点キック**＝撃つとクロスヘアが実際に跳ね上がる量。単位は度／発。左右は ± の範囲でランダム。
跳ね上がりの立ち上がり／戻り方・ADS中の減衰率は銃ごとではなく共通の定数 → [../design/recoil.md](../design/recoil.md)。

実装済みの銃のみ。未実装の銃は追加時に決める。

| 銃 | 垂直（上） | 水平（±） |
|----|----------|----------|
| グロック | 1.1 | 0.35 |
| AK系 | 1.8 | 0.6 |
| M4系 | 1.3 | 0.45 |
| その他 | ⬜未定 | ⬜未定 |

反動は3層（①視点キック ②銃モデルの跳ね ③着弾の拡散）に分かれ、上表は①のみ。②は作者制作の`fire`アニメーション、③は**腰だめの基本拡散（`hipSpreadDeg`、glock 2.0°／AK47 3.0°／M4A1 2.5°。すべて🟡仮）がサーバー権威で実装済み**——ADS中は拡散0。連射・移動によるブルームは未実装 → [../design/recoil.md](../design/recoil.md)。

### 耐久劣化しきい値（仮）

最大耐久 = 1500（発射数の目安）。機関部交換で全回復。

| 耐久残量 | 状態 | 効果 |
|---------|------|------|
| 100–61% | 正常 | 影響なし |
| 60–31% | 精度低下 | 弾拡散 +20% |
| 30–11% | 連射低下 | 連射レート −25% |
| 10–0% | ジャム | 発射ごと15%でジャム発生（リロード操作で解除） |

## アタッチメント種類

1. サイト
2. マガジン
3. マズルデバイス（サプレッサー、フラッシュハイダー／マズルブレーキ、銃剣）
4. ストック
5. ウェポンライト

## マズルデバイス仕様

| 種類 | 効果 |
|-----|------|
| サプレッサー | 発射音軽減・マズルフラッシュ非表示 |
| フラッシュハイダー／マズルブレーキ | 反動軽減・マズルフラッシュ軽減 |
| 銃剣 | 近接攻撃可能（近接システムは [04-enemies.md](04-enemies.md#近接システム) に統合） |

- マズルフラッシュはレイヤー分けで実装し、ブロック越しでは見えない

## サイト・照準仕様

- スコープを覗いても**画面全体のFOVは変化しない**
- スコープのレンズ部分のみ拡大表示（PiPスコープ）
- サイトの前後位置によって見え方が変わる

| サイト位置 | サイトの見た目 | 視野 |
|-----------|-------------|------|
| 後ろ寄り（目に近い） | サイトが大きく画面を占める | 狭い |
| 前寄り（銃口寄り） | ドットが小さい | 広い |

- **精度への影響なし**（見た目のみ）
- FOVの数値は gunpack のアタッチメント定義 `fov_near` / `fov_far` で制御 → [01-gunpack.md](01-gunpack.md#アタッチメント定義アタッチメント側)

### PiPスコープの描画方式

| 方式 | 品質 | 負荷 |
|-----|------|------|
| PiP（別カメラレンダリング） | リアル | 重い |
| 疑似ズーム（レンズ部分のFOV変更） | やや劣る | 軽い |

- デフォルトは**疑似ズーム**
- ゲーム設定でPiPに切り替え可能

## その他銃仕様

- リロード・サイト照準モーションの追加（モーション詳細は [06-animations.md](06-animations.md)）
- 弾薬種類に応じて使用可能
- オープンボルト・クローズドボルト種類分け
- ボルト内弾薬（薬室）：有り無しでリロードモーションが変化
- 拡張マガジンはリアル準拠
- 耐久値に応じて劣化：精度低下 → 連射力低下 → ジャム発生
- 耐久値は機関部交換で回復（機関部アイテムは [03-items.md](03-items.md#その他アイテム)）
- フラッシュライトによるプレイヤーへの目くらまし
