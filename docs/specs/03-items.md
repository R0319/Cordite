## 🟡 仮値（要調整）

> 防具の数値は仮確定。後でバランス調整する前提。防御力は「被ダメージ軽減率」、耐久値は「吸収できるダメージ量の目安」。

## 防具仕様

### スロット仕様

| スロット | 内容 |
|---------|------|
| ヘルメット | このModのヘルメット |
| チェスト | このModのボディアーマー（装備するとレギンスロックされる） |
| レギンス | ロック（チェスト装備時） |
| ブーツ | バニラそのまま |

### ボディアーマー

- プレート1枚のみ換装可能（前後なし）
- 移動速度への影響なし
- プレート素材で防御力・耐久値が変化

| 素材 | 防御力（軽減率） | 耐久値 |
|-----|--------------|-------|
| 銅 | 10% | 200 |
| 鉄 | 25% | 400 |
| 金 | 30% | 150 |
| ダイヤ | 45% | 800 |
| ネザライト | 55% | 1200 |

- 工業Mod導入時はセラミック等の素材追加も想定（後回し）

### ヘルメット

- アタッチメントはバイザーとナイトビジョンのみ

| ナイトビジョン種類 | トンネルビジョン |
|----------------|---------------|
| 一眼 | 強い（かぼちゃに近い） |
| 二眼 | 中程度 |
| 四眼 | なし |

- 敵にも防具を装備させる予定（[04-enemies.md](04-enemies.md#防具)）
