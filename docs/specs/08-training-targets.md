# 08. 的NPC / 射撃ターゲット仕様 🔵 検討中

> **範囲**: 射撃練習用の的NPC（GCCMod のような練習ターゲット）。戦闘用の敵とは別物 → 戦う敵は [04-enemies.md](04-enemies.md)。
> 用語・凡例は [README.md](README.md) を参照。数値は 🟡 仮値（後で調整）。

## 目的

- プレイヤーが銃の挙動（ダメージ・弾道・反動・射程減衰）を安全に試せる的
- ダメージ数値やヒット位置をフィードバック表示して調整に使える

## 的の種類（仮）

| 種類 | 挙動 |
|-----|------|
| 静止ターゲット | 動かない。基本の的 |
| ポップアップ | 撃つと倒れ、一定時間後に復帰 |
| 移動ターゲット | レール/経路上を左右に往復 |
| リアクション | ヒットで揺れる・音が鳴るなどの反応のみ（HP無限） |

## フィードバック機能（仮）

- ヒット時にダメージ数値を表示（ホログラム/パーティクル）
- ヒット部位（頭/胴/手足）に応じた表示（部位倍率は [02-guns.md](02-guns.md#ダメージ計算式仮)）
- 命中/被弾のカウンタ・リセットボタン（近接右クリック等）
- 🔵 検討: 一定範囲の的をまとめてリセットする操作

## 設置・入手（仮）

- アイテムとして設置（クラフト or クリエイティブタブ）
- 設置後に種類・挙動を設定（GUI or 右クリックで切替）
- 🔢 要調整: 復帰時間・移動速度・往復距離などの数値

## 実装メモ

- 戦闘AIは不要。敵（[04-enemies.md](04-enemies.md)）とは別エンティティ/別系統で実装
- ダメージ表示はサーバーで算出した値をクライアントに送って表示（サーバー権威 → [../design/00-architecture.md](../design/00-architecture.md)）
